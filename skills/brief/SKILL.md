# Brief

The request is whatever the user typed after `brief`.

Do no work yet. Reply with exactly these 3 lines, then stop:

1. **Goal:** what the user is trying to achieve, in plain words.
2. **For + format:** who will see it, and the exact output (short message, full write-up, PDF, web page, code change).
3. **Tools:** the tools you will use. For research, name them (for example browser, Perplexity, Reddit tool). Never swap in built-in web search without asking.

End with: "OK to start?" Do not start until the user says OK. If they change something, apply it and start; no need to re-brief for small changes.
